# Evidências da apresentação

Use o [guia de evidências](GUIA_EVIDENCIAS.md) para mapear cada critério ACE-01 a ACE-10, nomear capturas e preencher o [modelo de registro](modelo-registro.md). As pastas são apenas organizadores; não representam testes já executados.

Armazene capturas e logs sem tokens, senhas, arquivos `.env`, state Terraform ou dados pessoais:

- `cenario-1-criacao-inicial/`
- `cenario-2-atualizacao/`
- `cenario-3-idempotencia/`
- `ace-03-isolamento/`
- `ace-07-recuperacao/`
- `ace-09-custos/`
- `ace-10-transferencia/`

Inclua a URL e o número do run, mas oculte credenciais e qualquer conteúdo sensível antes de compartilhar os arquivos.
