# Evidências da apresentação

Armazene capturas e logs dos três cenários, sem tokens, senhas, arquivos `.env` ou state:

- `cenario-1-criacao-inicial/`
- `cenario-2-atualizacao/`
- `cenario-3-idempotencia/`

Para cada cenário, registre a execução do workflow, o resultado do Terraform/Ansible e a validação funcional ou de saúde correspondente.

Use o documento [Roteiro de Evidências PM-04](Roteiro_Evidencias_PM04.docx) para seguir os passos, nomear as capturas e registrar os resultados.
